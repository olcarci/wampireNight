Vampire Night Bell Link - iPhone kullanımı

1) ZIP dosyasını aç.
2) Klasörü bir web alanına yükle. En kolayı: GitHub Pages, Netlify veya kendi hostingin.
3) iPhone'da Safari ile index.html adresini aç.
4) Paylaş butonuna bas > Ana Ekrana Ekle.
5) Ana ekrandaki VampireNight ikonundan oyun tam ekran açılır.

Not: iPhone'da PWA/uygulama gibi çalışma için Safari üzerinden HTTPS bağlantı gerekir. Sadece Dosyalar uygulamasından açılırsa oyun çalışabilir ama Ana Ekrana Ekle ve offline kayıt özellikleri tam çalışmayabilir.
